# G1 固定站位提篮与放置

在已验证的提篮运行时上增加搬移、接触反馈缓降、持续桌面支撑门限、张手、退手及完整任务验收。实验结果和复现命令见[实验目录](../../experiments/20260926_g1_basket_place/README.md)及[实测报告](../../experiments/20260926_g1_basket_place/REPORT.md)。

- `basket_place_supervisor.py`：复用实际状态右臂IK和SONIC站立平衡，按物体实际位置衔接阶段；支撑不足时有界调整，不按预设时间假定已落桌。
- `basket_place_audit.py`：检查全部搬移状态中的抓握与离桌、完整事件顺序、释放前支撑及退手后独立稳定放置，保留失败原因。
- 扩增脚本：独立随机初始XY/yaw和桌面目标XY，从种子终态估计一次固定的释放偏移，每条重新执行物理；不是视频重建重跑或状态回放。

本任务使用位置目标，要求最终直立，但不要求给定偏航；不宣称精密朝向放置。视频输入缺失，规格由现有场景人工设计。双手搬运、持篮行走与阶段C仍未验证。

## 紧凑视频数据

`python -m g1_realtosim.render ... --profile rt2 --video-only`保留H.264视频、逐帧控制索引和相机矩阵，省去重复的无损RGB数组。它与原始50Hz状态/200Hz物理子步记录配套使用，实验`datasets/*.json`包含明确的动作槽索引及valid掩码。该模式不是自包含aligned HDF5；调用原无损导出器会明确报错。需要无损RGB时不传`--video-only`，使用原渲染/导出路径。

默认渲染行为不变。物理成功、数据完整性和视觉训练验收分开记录，未完成原速连续视觉验收时`training_eligible=false`。
