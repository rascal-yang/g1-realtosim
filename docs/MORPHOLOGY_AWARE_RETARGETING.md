# 人体尺寸不同：保留任务约束的 G1 重定向

## GRAIL 实际采用的先验

[GRAIL 官方项目](https://research.nvidia.com/labs/dair/grail/)从已知资产、相机、场景尺度和接近目标机器人比例的人体角色生成视频。官方 `grail/models/g1_smplx_model.py` 的 `G1ProportionSMPLX` 加载预先制作的 G1 比例 T-pose 网格，替换 SMPL-X 的 `v_template`，将通用形状/表情方向置零，并缩放姿态修正。HOI 优化和 GMR 可以使用这个模型。官方还训练物体交互跟踪策略，不能把最终操作能力全部归因于骨架。

真实拍摄的成年人视频没有上述先验。把身高统一缩放、复制关节角或只替换骨架，会改变手物距离和脚部支撑，不能保证原任务仍可执行。

## 对真实视频采用的约束

1. 场景、物体保持真实米制尺寸。人体模型与 G1 的尺度匹配单独处理，不缩小真实物体来制造成功。
2. 从人体视频获取动作阶段、接触对象、接触时序、非接触阶段的运动参考。把接触点存成物体局部坐标，明确遮挡与估计误差。
3. 按实际 G1/Revo2 模型优化站位、脚步、根位姿、躯干和双手。接触点/法线、足底支撑、关节限位、碰撞与动力学可行性优先，人体姿态是可调整的参考。
4. 单手抓法不适合实际手开口或物体材质时，显式重新规划双手夹持/侧缘抓取。保留“拿起并搬运”的任务目标，记录抓法变化；不得称为原动作逐帧复现。
5. 接触前检测两脚是否真的落地。不能在脚还悬空/翘起时使用双脚全接触逆动力学假设。支撑模式切换必须有观测依据。
6. 执行时联合控制手、重心和支撑力。静态 IK 的脚位/重心软约束不是动态平衡保证。新控制器先验证正常站立，再测试接近、触碰、夹持、试抬。
7. 夹持确认需要分离法向与切向接触。双手分别在箱侧接触时，可检验沿夹持轴的相向压力；拇指压在顶面的共同竖直反力会使两手总合力方向不相反。规则只允许进入试抬，不等价于抓取成功。
8. 成功必须由实际物体离地、持续持有、支撑状态和掉落检查判断。失败时停在接触阶段，不按原视频时钟继续“空手搬运”。

## 本机实现与边界

实验目录：`../experiments/20260923_contact_preserving_retarget`。

- `scripts/morphology_audit.py`：人体与 G1 的近似肢段长度对比。
- `scripts/search_stance.py`：站距、站宽候选，使用实际机器人几何评估双手接触、足位和重心误差。
- `code/bimanual_contact.py`：按原尺度箱子定向包围盒规划双手侧向抓取，再做全身 IK。
- `code/contact_wbc.py`：双脚支撑的逆动力学 QP，包含浮动基动力学、单向支撑力、足底摩擦锥、关节力矩/范围约束和状态反馈。
- `code/runtime_adapter.py`：SONIC 初始稳定，随后显式转交 QP 力矩控制；记录实际指令和接触。它不是 GRAIL 发布的交互策略。

这是局部物理验证和任务适配原型，尚不是任意视频、物体和场景都能自动成功的通用重定向器。逆动力学中的 Revo2 使用集中质量近似；当前足部接触模型假设平地双脚支撑。抓取时没有外部 GPT API。最终结果以各轮 `audit.json` 和实验报告为准。

## 2026-09-23 已验证的拾取结果

在原尺寸、原质量/摩擦纸箱上，第012轮完成正常站立→双脚支撑下蹲→双手侧夹→抬起→持箱站起，物理时长29.96 s，全箱离地最高38.25 cm，持续持有19.30 s直到结束，无最终掉落。前面的扩大位移上限没有解决滑落；向内力矩前馈与实测压力门槛共同调整后，本次单场景通过。实际压力约2.1–2.2 N/侧，小于4 N设定，不可用目标值替代实测值。

这条证据验证拾取/站立子任务，不是原视频全段搬运的成功率。成功实际状态已保存为实验内 `retarget/successful_pickup_stand_hint.npz`；它只能作为接触修正的参考。头部和第三人称RT2视频位于实验 `renders/trial012_head`、`renders/trial012_source`。视觉验收和完整碰撞认证仍未通过，不标为training-ready。

后续跨形态迁移应把“接触点、支撑模式、夹持阶段、物体目标”作为任务表示，再对机器人重新求可行运动。形态比例模板用于减少初始误差，不能代替这些约束与闭环执行。
