# 直接制作G1交互动画

[2026-09-27实验](../../experiments/20260927_blender_g1_interaction/README.md)从GPT编写的运动规格、既有G1/Revo2和办公室资产生成可编辑Blender动画，再从保存动画的实际连杆变换导出根/关节/物体轨迹。人体视频重建和GMR不适用于这个已经具有机器人关节结构的直接入口，本次不调用。

导出的CSV/NPZ是运动学参考，不是`g1_capture_v1`物理记录，不能直接送入现有dataset导出器冒充真实控制命令。后续物理适配从读回动画提取技能约束，使用既有SONIC站立控制、实际状态右臂IK和接触门限重新执行；实际状态、命令及完整任务成功单独验收。不声称34秒原始动画关节轨迹已被原时序无反馈跟踪，也不声称已实现实机迁移。
