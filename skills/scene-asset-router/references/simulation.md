# 面向 Isaac Sim 和机器人采集的资产检查

在交付仿真资产、Real-to-Sim 结果或可交互物体时读取。展示任务不自动增加完整物理流程。

## 参数依据

对关键参数记录数值、单位、来源与适用范围，区分 `measured`、`fitted`、`estimated` 和 `designed`。未知量可以留空或采用明确的估计区间，不使用伪造的置信度数字。

| 参数 | 可用依据 | 不能作出的推断 |
|---|---|---|
| 尺寸、位姿 | 实测标记/尺寸、多视角几何、已标定坐标变换 | 单张生成图给出真实绝对尺度 |
| PBR 材质 | 观测拟合、材料类别先验、设计目标 | 一张照片唯一确定反照率、光照和粗糙度 |
| 质量、重心、惯量 | 称重、分部件密度先验、动态拟合 | 外形准确就代表内部质量分布准确 |
| 摩擦 | 指定接触材料的滑动或推拉测试 | 渲染粗糙度等于摩擦系数；桌面与手指使用同一真实摩擦 |
| 刚度、阻尼、回弹 | 已知载荷或受控交互下的形变观测和拟合 | 生成视频能证明实物的受力响应 |

纯文字生成场景允许使用设计参数；对应资产是合成场景资产。真实场景重建缺少物理测量时，仍可交付并标记未校准，不能宣称已减小真实动力学误差。

## 视觉和物理表示

- 保存高质量视觉网格及 PBR 贴图，为物理构建适当精度的独立碰撞体；记录二者变换关系。
- 抓取物体保留把手孔、腋下间隙、突起和手指接近空间。单个凸包可能填平这些区域，需要分解或使用目标引擎支持的其他表示。
- 背景装饰可按任务使用简化碰撞；可操作对象按接触精度检查。不要统一对整个房间做细粒度动态碰撞。
- 图生 3D 的单体外观不自动包含关节和内部结构。需要转动或开合的部件应拆分并建立可验证的连接。
- 毛绒玩偶须明确选择刚体近似、关节/弹簧近似或可形变体；毛发和布料纹理不代表可压缩。用户要求弹性时，需要实际压缩释放测试，近似模型须说明能表达的行为范围。
- 物理辨识工具的参数依赖其模型与求解器。迁移到 PhysX 等目标引擎后，重新检查响应；不假设可以逐字段复制。

## 导出与验证

1. 检查目标 Isaac Sim/PhysX 版本和所选碰撞、材质、可形变功能支持情况，使用匹配版本的 API。
2. 导出资产时明确 `metersPerUnit`、`upAxis`、物体局部坐标、场景位姿、惯性与碰撞配置；检查重复缩放、镜像、负尺度和变换未应用问题。
3. 材质使用目标引擎实际支持的节点或转换方式；打包依赖。相对路径重定位后重新打开，确认贴图、法线、透明度等关键效果。
4. 在目标引擎中实际运行与用途有关的小测试：静态支撑与穿插、动态物体落桌稳定性、接触碰撞是否吻合；弹性资产增加压缩与释放。记录时步、求解器设置和结果。
5. 若用于机器人数据采集，检查机器人第一视角的可见尺度和材质，确认物体语义/实例 ID、位姿坐标系和所需相机标定信息能被采集器读取。

只在用户请求完整轨迹/数据时继续跑机器人任务；资产建模完成不自动扩大为抓取实验。实际运行 G1/Revo 2 抓取时，再使用可用的 `g1-grasp-runtime-review` skill。

## 分开报告三个结论

- 外观：通过/失败/未检查，附具体视角。
- 仿真可用性：通过/失败/未运行，附测试依据。
- 实物校准：哪些参数有测量或拟合、哪些仍为估计；未知处保留合理范围。

仿真落桌或抓取成功只说明特定模型和配置下可运行，不足以证明实物一致性。批量任务可使用参数区间做随机化，但不能代替精度验证。
